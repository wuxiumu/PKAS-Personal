# 金句模板设计

## 🎯 功能目标

> **一个支持在线编辑、海报分享、移动端友好的金句管理系统**

### 核心需求

- ✨ **金句管理**：收集、整理、分类个人金句
- 📝 **在线编辑**：支持 Markdown 格式，可直接在浏览器中编辑
- 🎨 **海报生成**：一键生成精美的分享海报图片
- 📱 **移动端友好**：适配手机、平板等移动设备
- 🔍 **搜索与筛选**：按标签、来源、日期等维度查找
- 📊 **数据可视化**：统计金句数量、来源分布等

## 1️⃣ 数据模型设计

### Markdown Frontmatter 格式

```yaml
---
id: quote_20260117_123456
title: 金句标题（可选，用于分组）
content: 这是金句的正文内容
author: 作者名称（可选）
source: 来源（书籍/文章/演讲等，可选）
source_url: 来源链接（可选）
tags:
  - 标签1
  - 标签2
category: 分类（如：读书、思考、管理）
created_at: 2026-01-17 12:34:56
updated_at: 2026-01-17 12:34:56
status: published
poster_template: default  # 海报模板名称
---
```

### JSON 数据格式

```json
{
  "id": "quote_20260117_123456",
  "title": "金句标题",
  "content": "这是金句的正文内容",
  "author": "作者名称",
  "source": "来源",
  "source_url": "https://example.com",
  "tags": ["标签1", "标签2"],
  "category": "读书",
  "created_at": "2026-01-17 12:34:56",
  "updated_at": "2026-01-17 12:34:56",
  "status": "published",
  "poster_template": "default"
}
```

### 数据验证规则

- `id`: 必须唯一，格式：`quote_YYYYMMDD_HHMMSS`
- `content`: 必填，不能为空
- `created_at`: 必填，格式：`YYYY-MM-DD HH:MM:SS`
- `status`: 必填，值为 `published` 或 `draft`
- `tags`: 数组，每个标签长度不超过 20 字符
- `category`: 可选，预定义分类列表

## 4️⃣ 海报生成功能

### 技术方案

#### 方案 1：Canvas + html2canvas（推荐）

**优点：**
- 纯前端实现，无需后端
- 支持自定义样式
- 兼容性好

**实现步骤：**
1. 使用 Canvas API 绘制海报
2. 或使用 html2canvas 将 DOM 转换为图片
3. 导出为 PNG/JPG

#### 方案 2：服务端生成（未来扩展）

**优点：**
- 性能更好
- 支持复杂模板
- 可以缓存

**技术栈：**
- Python: Pillow + 模板引擎
- Node.js: Canvas + Sharp

## 5️⃣ 移动端适配

### 响应式设计

- **断点设置：**
  - 移动端：< 768px
  - 平板：768px - 1024px
  - 桌面端：> 1024px

### 移动端优化

1. **触摸优化：**
   - 按钮尺寸 ≥ 44px × 44px
   - 支持滑动操作
   - 长按菜单

2. **性能优化：**
   - 图片懒加载
   - 虚拟滚动（长列表）
   - 防抖搜索

3. **离线支持：**
   - Service Worker 缓存
   - IndexedDB 存储草稿
