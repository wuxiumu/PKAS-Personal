# 金句功能使用说明

## 📋 功能概述

金句管理系统已实现基础功能（MVP），包括：

- ✅ 金句列表页（搜索、筛选、分页）
- ✅ 金句详情页
- ✅ 数据构建器（Python）
- ✅ SEO 优化

## 🚀 快速开始

### 1. 创建金句文件

在 `content/quotes/` 目录下创建 Markdown 文件，建议按日期组织：

```
content/quotes/
├── 2026/
│   ├── 01/
│   │   ├── 20260117120000-quote-slug.md
│   │   └── ...
```

### 2. 金句文件格式

每个金句文件应包含 Frontmatter 和内容：

```yaml
---
id: quote_20260117_120000
title: 金句标题（可选）
content: 这是金句的正文内容
author: 作者名称（可选）
source: 来源（可选）
source_url: 来源链接（可选）
tags:
  - 标签1
  - 标签2
category: 分类（可选）
created_at: 2026-01-17 12:00:00
updated_at: 2026-01-17 12:00:00
status: published  # 或 draft
poster_template: default
---

金句的正文内容（如果 frontmatter 中有 content，则此部分可选）
```

### 3. 构建数据

运行构建脚本生成 `quotes.json`：

```bash
python3 scripts/build_quotes.py
```

### 4. 访问前端

启动前端开发服务器：

```bash
cd frontend
npm run dev
```

访问 `http://localhost:5173/quotes` 查看金句库。

## 🎯 功能特性

### 金句列表页

- **搜索功能**：支持搜索标题、内容、作者、来源、标签
- **标签筛选**：点击标签筛选相关金句
- **分类筛选**：按分类筛选金句
- **视图切换**：网格视图和列表视图
- **分页**：每页显示 12 条金句
- **URL 参数同步**：搜索和筛选条件会同步到 URL

### 金句详情页

- **完整显示**：显示金句的完整内容和元信息
- **标签跳转**：点击标签跳转到该标签的金句列表
- **操作按钮**：
  - 编辑（待实现）
  - 生成海报（待实现）
  - 复制内容
  - 分享链接

## 🔧 数据验证规则

构建器会验证以下规则：

- `id`: 必须唯一，格式：`quote_YYYYMMDD_HHMMSS`
- `content`: 必填，不能为空
- `created_at`: 必填，格式：`YYYY-MM-DD HH:MM:SS` 或 `YYYY-MM-DD`
- `status`: 必填，值为 `published` 或 `draft`
- `tags`: 数组，每个标签长度不超过 20 字符

## 🐛 故障排除

### 构建失败

1. 检查 Markdown 文件格式是否正确
2. 检查 Frontmatter 是否完整
3. 查看构建脚本输出的错误信息

### 前端显示问题

1. 确保已运行构建脚本生成 `quotes.json`
2. 检查浏览器控制台是否有错误
3. 确保所有依赖已安装：`npm install`
