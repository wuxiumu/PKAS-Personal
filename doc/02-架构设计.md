# 架构设计

## 🧱 系统架构

```
Markdown / CSV / 本地数据
        ↓
Python 离线处理 & 聚合
        ↓
标准化 JSON 数据
        ↓
React 前端（Blog / Dashboard）
```

## 核心设计理念

- **Python**：数据构建器（不是在线后端）
- **React**：展示 & 管理
- **JSON**：唯一数据交换格式
- **Markdown**：内容源，长期可读

## 数据流

### 1. 内容输入
- Markdown 文件（带 frontmatter）
- CSV 数据（资产、成本等）
- 本地结构化数据

### 2. 数据处理
- Python 脚本解析和校验
- 数据标准化和聚合
- 生成统一的 JSON 格式

### 3. 前端展示
- React 应用读取 JSON
- 渲染 Blog 页面
- 提供管理界面

## 为什么这个架构适合 AI 接管

- AI → 生成 Markdown
- Python → 校验 + build JSON
- React → 自动渲染

👉 **人只负责判断，不负责搬运**
