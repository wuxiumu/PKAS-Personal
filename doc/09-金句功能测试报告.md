## 🚀 运行指南

### 1. 构建数据
```bash
python3 scripts/build_quotes.py
```

### 2. 启动开发服务器
```bash
cd frontend
npm run dev
```

### 3. 访问页面
- 金句列表: http://localhost:5173/quotes
- 新建金句: http://localhost:5173/quotes/new
- 编辑金句: http://localhost:5173/quotes/:slug/edit

## 📝 使用说明

### 创建新金句
1. 访问 `/quotes/new`
2. 填写表单（ID、内容为必填）
3. 实时预览效果
4. 点击"保存"下载 Markdown 文件
5. 将文件保存到 `content/quotes/` 目录
6. 运行构建器更新数据

### 编辑现有金句
1. 在金句列表或详情页点击"编辑"
2. 修改内容
3. 草稿会自动保存到 localStorage
4. 点击"保存"下载更新后的文件
5. 替换原文件后运行构建器

### 草稿管理
- 草稿自动保存到 localStorage（1秒延迟）
- 草稿键名: `quote_draft_${slug}` 或 `quote_draft_new`
- 可以手动清除草稿

## ⚠️ 注意事项

1. **编辑器功能**：
   - 当前编辑器只生成 Markdown 文件，需要手动保存到 `content/quotes/` 目录
   - 未来可以扩展为直接保存到文件系统（需要后端 API）

2. **数据同步**：
   - 修改文件后需要重新运行构建器
   - 可以考虑添加文件监听自动构建

3. **移动端**：
   - 编辑器在移动端可能需要优化布局
   - 建议使用上下分栏而非左右分栏
